# Photon Lab

A real-time path tracer that runs in the browser. Three scenes lit only by simulated light bounces: glass refraction, dispersion, caustics, colour bleed and depth of field.

Live: https://saksham.digital/photon-lab/

Drag to orbit, scroll to zoom, click an object to focus on it, keys 1 to 3 to switch scenes. Hold still and the image sharpens. One HTML file, three.js r128, needs WebGL 2.
